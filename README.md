# SaaS Permitting Platform

Plataforma SaaS B2B2B para la Gestión Inteligente de Permisos de Construcción.

## Estructura del Proyecto

Esta carpeta contiene el código fuente, la infraestructura y el modelo de datos de la plataforma.

- `docker-compose.yml`: Infraestructura de desarrollo local (PostgreSQL, Redis, MinIO).
- `database/`: Scripts SQL de base de datos y migraciones (PostgreSQL con Row Level Security).
- `services/`: Microservicios de la plataforma.
